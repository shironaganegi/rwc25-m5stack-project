# アプリケーションセットアップ

## 🗺️ マップ機能

このアプリケーションは **OpenStreetMap + Leaflet.js** を使用して地図機能を実装しています。
完全無料でAPIキー不要、外部依存なしで動作します。

### マップ機能の特徴
- **APIキー不要**: 完全無料で制限なし
- **店舗検索**: 店舗名での検索とフィルタリング
- **リアルタイム情報**: セール情報と混雑率の表示
- **インタラクティブマップ**: ズーム、パン、マーカークリック
- **レスポンシブデザイン**: モバイル対応
- **フィルタリング**: 混雑率による絞り込み

## 🗄️ データベース構造

このアプリケーションは `supermarket_app` データベースを使用します。

### テーブル構成
- **users**: ユーザー（店舗スタッフ）情報
- **categories**: 商品カテゴリ
- **products**: 商品情報（価格、在庫など）
- **sales**: セール情報（割引、期間など）
- **sales_data**: 売上実績データ
- **sales_targets**: 売上目標設定
- **notification_settings**: 通知設定

### サンプルデータ
初期データとして以下が自動作成されます：
- 管理ユーザー（admin/admin@supermarket.com）
- 5つの基本カテゴリ（食品、飲料、日用品、冷凍食品、お菓子）
- 5つのサンプル商品
- 日次売上目標（¥580,000）

## 環境設定

### 1. 環境変数の設定
`.env.example`をコピーして`.env`ファイルを作成してください：

```bash
cp .env.example .env
```

### 2. Dockerでの実行
```bash
docker-compose up -d
```

### 3. データベース動作確認
```
http://localhost:8000/test_db.php
```

### 4. マップページへのアクセス
```
http://localhost:8000/map/map.php
```

## 開発者向け情報

### データベース接続
`/includes/database.php`ファイルでデータベース操作を統一管理：

```php
// データベース接続
$db = Database::getInstance();

// 全商品取得
$products = $db->getAllProducts();

// カテゴリ別商品取得
$products = $db->getProductsByCategory(1);

// アクティブなセール取得
$sales = $db->getActiveSales();
```

### マップ実装の詳細
- **OpenStreetMap**: オープンソースの地図データ
- **Leaflet.js**: 軽量でモダンな地図ライブラリ
- **カスタムマーカー**: 店舗タイプ別のアイコン表示
- **ポップアップ**: 店舗情報の詳細表示
- **検索・フィルタリング**: リアルタイムな店舗検索

### 店舗データ構造
```javascript
{
    name: '店舗名',
    lat: 緯度,
    lng: 経度,
    distance: '距離',
    saleTime: 'セール時間',
    congestion: '混雑率',
    saleInfo: 'セール情報',
    category: 'カテゴリ'
}
```

### カスタマイズポイント
- `stores`配列に新しい店舗データを追加
- マーカーアイコンの色やスタイルの変更
- ポップアップ表示内容のカスタマイズ
- フィルタリング条件の追加
- データベースからの動的データ取得

## セキュリティと運用

### 依存関係
- **外部API**: なし（OpenStreetMapのみ）
- **外部認証**: なし  
- **課金**: なし
- **制限**: なし

### データベース設定
- **ホスト**: localhost:53306
- **データベース名**: supermarket_app
- **文字セット**: utf8mb4
- **照合順序**: utf8mb4_unicode_ci

### データ更新
店舗情報は現在JavaScript内にハードコーディングされています。
データベースと連携して動的な情報表示も実装可能です。

## 開発者向け
新しい環境変数を追加した場合は、`.env.example`ファイルも同時に更新してください。
