# アプリケーションセットアップ

## 🗺️ マップ機能

このアプリケーションは **OpenStreetMap + Leaflet.js** を使用して地図機能を実装しています。
完全無料でAPIキー不要、外部依存なしで動作します。

### マップ機能の特徴
- **APIキー不要**: 完全無料で制限なし
- **店舗検索**: 店舗名での検索とフィルタリング
- **リアルタイム情報**: セール情報と混雑率の表示
- **インタラクティブマップ**: ズーム、パン、マーカークリック
- **レスポンシブデザイン**: モバイル対応
- **フィルタリング**: 混雑率による絞り込み

## 環境設定

### 1. 環境変数の設定
`.env.example`をコピーして`.env`ファイルを作成してください：

```bash
cp .env.example .env
```

### 2. Dockerでの実行
```bash
docker-compose up -d
```

### 3. マップページへのアクセス
```
http://localhost:8888/map/map.php
```

## 開発者向け情報

### マップ実装の詳細
- **OpenStreetMap**: オープンソースの地図データ
- **Leaflet.js**: 軽量でモダンな地図ライブラリ
- **カスタムマーカー**: 店舗タイプ別のアイコン表示
- **ポップアップ**: 店舗情報の詳細表示
- **検索・フィルタリング**: リアルタイムな店舗検索

### 店舗データ構造
```javascript
{
    name: '店舗名',
    lat: 緯度,
    lng: 経度,
    distance: '距離',
    saleTime: 'セール時間',
    congestion: '混雑率',
    saleInfo: 'セール情報',
    category: 'カテゴリ'
}
```

### カスタマイズポイント
- `stores`配列に新しい店舗データを追加
- マーカーアイコンの色やスタイルの変更
- ポップアップ表示内容のカスタマイズ
- フィルタリング条件の追加

## セキュリティと運用

### 依存関係
- **外部API**: なし
- **外部認証**: なし  
- **課金**: なし
- **制限**: なし

### データ更新
店舗情報は現在JavaScript内にハードコーディングされています。
将来的にはデータベースやAPIとの連携も可能です。

## 開発者向け
新しい環境変数を追加した場合は、`.env.example`ファイルも同時に更新してください。
