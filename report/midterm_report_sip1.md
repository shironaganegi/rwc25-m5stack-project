## 2. 調査の概要
- 調査したアプリケーション:
    - 価格.com
    - マクドナルドアプリ
    - [トクバイ](https://tokubai.co.jp/product_categories)
- 使用した方法 (インタビュー、記事、Web など):

- 調査結果の概要:
    - 複数店舗のセール情報を含むスーパーの値段を広範囲かつ正確に公開しているサービスは存在していない
    - モバイルアプリにするとUI/UXが向上し、使用してもらいやすくなる

## 3. 問題の定義
- 社会問題 / ユーザーのニーズ:

    - レシピに必要な食材を整理して購入したい
    - 惣菜などの半額情報などでフードロス削減に繋げたい

- 証拠または根拠:自分たちの家族が手軽に確認できるアプリが欲しいという要望があったため

## 4. 現在のアイデア
- スーパーごとの値段比較 (長所、短所):安く買い物ができる、値段情報の入力の手間
- セール情報のまとめ(長所、短所):一目でさまざまな店のセールがわかる、セール情報の入力の手間
- 近くのスーパーに絞っての検索 (説明、長所、短所):MAP上で指で囲った部分のスーパーの情報を表示する、(記述必要)
- 買い物リストを使った買い物の最適化 (説明、長所、短所):買い物リストを作ると一番安くかえるスーパーが表示される、一目でわかる、(記述必要)
- 冷蔵庫内情報の可視化  (説明、長所、短所):冷蔵庫内の材料の残数や賞味期限の管理、出先で確認できる、冷蔵庫内の配置を考える必要がある
