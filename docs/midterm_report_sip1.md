## 2. 調査の概要

- 調査したアプリケーション:
  - 価格.com
  - マクドナルドアプリ
  - [トクバイ](https://tokubai.co.jp/product_categories)
- 使用した方法 (インタビュー、記事、Web など):
  - 「調査したアプリケーション」をチームで使用し、調査した。
- 調査結果の概要:
  - 複数店舗のセール情報を含むスーパーの値段を広範囲かつ正確に公開しているサービスは存在していない
  - モバイルアプリにするとUI/UXが向上し、使用してもらいやすくなる

## 3. 問題の定義

- 社会問題 / ユーザーのニーズ:
  - 食材をなるべく安く購入したい
  - レシピに必要な食材を整理して購入したい
  - 惣菜などの半額情報などでフードロス削減に繋げたい

- 証拠または根拠:自分たちの家族が手軽に確認できるアプリが欲しいという要望があったため

## 4. 現在のアイデア

| アイデア | 説明 | 長所 | 短所 |
|---------|------|------|------|
| スーパーごとの値段比較 | 各スーパーの商品価格を比較できる機能 | 安く買い物ができる | 値段情報の入力の手間 |
| セール情報のまとめ | 複数店舗のセール情報を一箇所に集約 | 一目でさまざまな店のセールがわかる | セール情報の入力の手間 |
| 近くのスーパーに絞っての検索 | MAP上で指で囲った部分のスーパーの情報を表示する | 近隣のスーパー情報に絞れる | 近くのスーパーにしかメリットがなくなる |
| 買い物リストを使った買い物の最適化 | 買い物リストを作ると一番安く買えるスーパーが表示される | 一目でわかる | 買い物リストに追加する手間がかかる |
| 冷蔵庫内情報の可視化 | 冷蔵庫内の材料の残数や賞味期限の管理 | 出先で確認できる | 冷蔵庫内の配置を考える必要がある |

## 5. 進捗状況

- 現在の進捗状況:
    - アプリのデザインはすでに完成し、開発に取り掛かることができる。
    - メンバーには使用する技術の習得をお願いしており、進捗としてはかなり順調である。
- アイデアの実現可能性（技術調査）:
    - M5Stackのスペック不足を考慮し、Webアプリのバックエンドとして処理を記述することで、処理速度や処理能力などの物理的な障壁はないと考える。
    - 処理内容の難易度はそれほど高くないと考えているため、実現可能性は高いと考える。
