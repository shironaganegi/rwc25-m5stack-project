# ポスターデザイン案：スーパーチープくん

**用紙サイズ:** A2 (縦 594mm × 横 420mm)
**デザインコンセプト:** 親しみやすく、お得感と信頼感を感じさせるデザイン。スーパーマーケットのチラシのような賑やかさと、システムの説明としての分かりやすさを両立させる。
**配色イメージ:**

* メインカラー：フレッシュな緑（野菜、信頼）、明るいオレンジ（お得感、活気）
* アクセントカラー：青（技術、知性）、赤（注目、セール）
* ベースカラー：白、薄いグレー（背景）

## ポスター構成案（上から順に配置）

### 1. ヘッダーエリア（最上部帯）

* **背景色:** 明るいオレンジまたは緑のグラデーションで目を引くように。
* **内容:**
* **タイトル（最大文字）:** スーパーチープくん
* **サブタイトル:** スーパー価格比較・買い物最適化システム
* **キャッチコピー（目立つように配置）:** 「最適な買い物を、もっと簡単に」
* **チーム名（右上に小さく配置）:** チーム：スーパー・ドリーム隊 !!



### 2. 導入エリア：背景と解決する課題

* **レイアウト:** 左右2分割または上下で「課題」と「解決策」を対比させる。
* **左側（または上段）：現状の課題（Before）**
* アイコン付きで分かりやすく表現（例：悩む主婦のアイコン、廃棄食材のアイコン）。
* **ユーザーの悩み:** どこのスーパーが安いか分からない、最適な店を選べない。
* **店舗の悩み:** 来店客数が予測できず、食材ロスが発生。


* **右側（または下段）：スーパーチープくんが提供する価値（After）**
* 解決を示す明るいアイコンを使用（例：笑顔の主婦、データを見る店長）。
* **ユーザーのメリット:** 最安値が分かる、家計管理が楽になる、冷蔵庫管理で無駄を削減。
* **店舗のメリット:** 購買データ・混雑状況の可視化、効果的なマーケティング、ロス削減。



### 3. システム構成図（中央エリア）

* **デザイン:**

## ポスターデザインのポイント（まとめ）

1. **視認性第一:** タイトル、キャッチコピー、見出しは遠くからでも読める大きなフォントを使用する。
2. **図と画像の活用:** システム構成図を中央に据え、スクリーンショットやデバイス写真を多用して、文字を読まなくても概要が伝わるようにする。
3. **情報の構造化:** 「課題→解決策→システム→機能→技術→現状」という論理的な流れを作り、枠線や背景色でセクションを明確に区切る。
4. **キャッチーな表現:** アイコンや短いフレーズ（「お得に買い物！」「効率的な運営！」など）を使って、見ていて楽しいポスターにする。
5. **QRコードへの誘導:** 興味を持った人がすぐに詳細情報にアクセスできるよう、QRコードは目立つ位置に配置し、何を読み取れるかを明記する。
