## 2. 開発するものの概要

### 2.1 ステークホルダーとアプリ概要  

- ステークホルダー：
  家計などを気にしてなるべく安く済ませたい主婦・お惣菜をよく買うお年寄り
  
- 解決したい課題：
  スーパーごとの価格が分からず、最適な店を選べない・お店側ではどれほどのお客さんが来るかのデータが少なく惣菜など食材が無駄になっている可能性がある点
- 得られる価値：
  家計をより管理しやすくできる
  購入者の購買データが可視化でき効果的なマーケティング戦略が組める
- アプリ概要：
  - システム名：スーパーチープくん
    - 主な機能：　
        - スーパーごとの値段比較
        - セール情報のまとめとリアルタイムな反映
        - 地図で囲ってスーパー検索
        - 買い物リストを使った買い物の最適化
        - 冷蔵庫内情報の可視化
