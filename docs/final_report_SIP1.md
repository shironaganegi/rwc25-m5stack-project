## 2. システム化の背景
- 注目した社会の状況：　スーパーごとの価格が分からず、最適な店を選べない・お店側ではどれほどのお客さんが来るかのデータが少なく惣菜など食材が無駄になっている可能性がある
- 対象となるユーザー：　家計などを気にしてなるべく安く済ませたい主婦・お惣菜をよく買うお年寄り
- 関連する主要なサービス：価格ドットコム・スーモの地図機能・トクバイ

## 3. 提案システムの概要
- システム名：　スーパーチープくん
- 主な機能：　
    - スーパーごとの値段比較
    - セール情報のまとめとリアルタイムな反映
    - 地図で囲ってスーパー検索
    - 買い物リストを使った買い物の最適化
    - 冷蔵庫内情報の可視化

- 画面レイアウト：　画面遷移がわかるように、インタフェースの案を記載する。操作がわかるような説明を入れる
- システム構成図：　![システム構成図](/docs/shop.png)

## 4. 進捗状況
- 何がどれだけ終わっているか：　![ガントチャート](/docs/gantt_chart.png)
- 技術調査の結果：M5Stackのスペック不足を考慮し、Webアプリのバックエンドとして処理を記述することで、処理速度や処理能力などの物理的な障壁はないと考える。そして、Webアプリの処理内容の難易度はそれほど高くないと考えているため、実現可能性は高いと言える。
