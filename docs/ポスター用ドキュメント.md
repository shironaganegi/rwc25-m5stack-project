# スーパーチープくん - ポスター用ドキュメント

## 📌 1. タイトル・システム名

**スーパーチープくん**  
スーパー価格比較・買い物最適化システム

---

## 🎯 2. 背景・解決する課題

### 社会問題
- **ユーザー側**: スーパーごとの価格が分からず、最適な店を選べない
- **店舗側**: どれほどのお客さんが来るかのデータが少なく、惣菜など食材が無駄になっている可能性がある

### 対象ユーザー
- 家計などを気にしてなるべく安く済ませたい主婦
- お惣菜をよく買うお年寄り

### 得られる価値
- **ユーザー側**: 家計をより管理しやすくできる
- **店舗側**: 購入者の購買データが可視化でき、効果的なマーケティング戦略が組める

---

## 🏗️ 3. システム構成

### 4つのアプリケーション

#### 3.1 ユーザー向けWebアプリ
- **URL**: `http://localhost:8000`
- **技術**: PHP, HTML, CSS, JavaScript
- **主な機能**:
  - ホーム画面（チラシ表示）
  - マップ機能（OpenStreetMap + Leaflet.js）
  - セール情報一覧
  - レシピ検索・詳細表示
  - 冷蔵庫リスト管理
  - お気に入り機能

#### 3.2 店舗向けWebアプリ
- **URL**: `http://localhost:3000`
- **技術**: PHP, HTML, CSS, JavaScript, Chart.js
- **主な機能**:
  - ダッシュボード（売上概要）
  - セール情報入力
  - 売上分析（日別・週別・月別グラフ）
  - 在庫アラート

#### 3.3 ユーザー向けM5Stackアプリ
- **技術**: MicroPython
- **主な機能**:
  - QRコード読み取り
  - 冷蔵庫への商品登録（Web API連携）
  - 商品情報表示

#### 3.4 店舗向けM5Stackアプリ
- **技術**: MicroPython
- **主な機能**:
  - 混雑率測定（人感センサー連携予定）
  - 混雑率データのWeb API送信

## ⚙️ 4. 主要機能

### ユーザー向け機能
1. **価格比較・セール情報**
   - 複数店舗のセール情報を一覧表示
   - 店舗別・商品別の検索

2. **地図機能**
   - OpenStreetMapによる店舗検索
   - 混雑率フィルタリング
   - 店舗情報の表示

3. **冷蔵庫管理**
   - 冷蔵庫内商品の登録・管理
   - M5StackのQRコード読み取りで簡単登録
   - 消費期限管理

4. **レシピ機能**
   - レシピ検索・詳細表示
   - 材料リスト表示

5. **お気に入り**
   - 店舗・商品のお気に入り登録

### 店舗向け機能
1. **売上管理**
   - 今日の売上概要
   - 前日比表示
   - 売上目標達成率

2. **セール情報入力**
   - セール商品の登録
   - 期間・価格設定

3. **売上分析**
   - 日別・週別・月別の売上推移グラフ
   - Chart.jsによる可視化

4. **混雑率管理**
   - M5Stackからの混雑率データ受信
   - 時系列データの保存

## 💻 5. 技術スタック

### フロントエンド
- **HTML5 / CSS3**: レスポンシブデザイン
- **JavaScript**: 
  - Leaflet.js（地図機能）
  - Chart.js（グラフ表示）
  - Lightbox（画像拡大）

### バックエンド
- **PHP**: サーバーサイド処理
- **MySQL**: データベース（Docker環境）

### ハードウェア
- **M5Stack**: マイコンボード
- **MicroPython**: M5Stack用プログラミング言語

### インフラ
- **Docker / Docker Compose**: コンテナ環境
- **Apache**: Webサーバー

### 外部サービス
- **OpenStreetMap**: 地図データ（APIキー不要）

---

## 📊 6. データベース構造

### 主要テーブル
- `users`: ユーザー（店舗スタッフ）情報
- `stores`: 店舗マスタ
- `products`: 商品情報
- `sales`: セール情報
- `sales_data`: 売上実績データ
- `sales_targets`: 売上目標設定
- `user_refrigerator`: 冷蔵庫内商品
- `user_favorite_stores`: お気に入り店舗
- `user_favorite_products`: お気に入り商品
- `recipes`: レシピ情報
- `recipe_ingredients`: レシピ材料
- `congestion_data`: 混雑率データ（時系列）
