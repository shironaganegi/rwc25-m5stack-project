## Githubの使い方について(初回)
Githubとは、ソースコードをネット上で管理できる便利なツールである。(社会に出てもよく使うよ！)
初回はネット上にある情報を自分のパソコンに持ってくる手順が必要になる。以下のコマンドを打つと作業ディレクトリにファイルができてしまうので要注意。できれば専用のファイルを作り、その中でやるといいと思う。
```ssh
git init
git clone https://github.com/KDIX-RWCProjects/RWC25-group07.git
```
以上のコマンドで自分のパソコンにソースコードを持ってくることができる。また、下に書いてある通り、ネットのコードをコマンドで変更することだってできる。

---- 
## Githubの使い方について(初回じゃない場合)
基本的には
```ssh
git add .

git commit -m "コミットメッセージ" 
    // ここのコミットメッセージは変更する内容を簡潔に表した日本語に置き換える。

git push
```
という手順でGithubにコードを反映できる。
